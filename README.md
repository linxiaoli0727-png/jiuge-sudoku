# 九格 · 单机数独

零依赖的本地数独游戏，所有题目都在浏览器内随机生成并保证唯一解。

## 启动

在终端运行：

```bash
/Users/xllin/sudoku-game/start-sudoku.command
```

也可以直接双击 `start-sudoku.command`，或在 Finder 中双击 `index.html`。

## 规则

- 三档难度：轻松（42 个提示）、进阶（34 个提示）、挑战（28 个提示）。
- 每题随机生成，不限时，并且保证只有一个解。
- 填入与答案不符的数字会立即标红，每次错误累计一次。
- 一局累计错误 5 次即失败，连续胜场清零。
- 同一难度连续赢 5 局会自动升阶；挑战难度为无限模式。
- 当前连胜、本级胜场和历史最高连胜保存在浏览器本地。
